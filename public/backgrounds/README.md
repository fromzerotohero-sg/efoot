## ✅ DOVE METTERE IL TUO SFONDO

Metti qui la tua immagine di sfondo!

### Nome del file
Puoi chiamarlo come vuoi, ad esempio:
- `background.jpg`
- `sfondo.png`
- `brain-bg.webp`
- `dashboard-background.jpg`

### Formati supportati
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.svg` (per pattern)

### Dopo aver caricato il file
Scrivimi il nome del file e lo configuro subito! 🚀

---

**Esempio:**
1. Carica `background.jpg` qui
2. Scrivimi: "Ho caricato `background.jpg`"
3. Io lo configuro e funziona! ✅
